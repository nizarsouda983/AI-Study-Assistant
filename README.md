# 📚 AI Study Assistant

AI Study Assistant is a web app that helps students study different topics using AI.

## ✨ Features

- 📖 AI-generated study lessons
- 📝 AI-generated quizzes
- 🧠 AI-generated flashcards
- 📷 Upload notes and study from them
- 💬 Ask the AI questions about your lesson
- 📚 Study history
- 📊 Progress tracking
- 🎯 Study goals
- 🔥 Study streaks

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express
- OpenAI API

## 🚀 How It Works

1. Enter a topic you want to study.
2. Choose an option like Study, Quiz, or Flashcards.
3. The AI creates study material based on your topic.
4. You can ask the AI questions and practice what you learned.

## 🔐 Security

The OpenAI API key is stored in a `.env` file and is not included in the GitHub repository.
